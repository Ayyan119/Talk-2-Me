# talk-to-me

> A voice-operated LLM Q&A system with short-term memory.

**Status:** Scaffolding only, no logic implemented yet.

## Setup Instructions

1. **Activate Virtual Environment:**
   ```bash
   source venv/bin/activate
   ```

2. **Install Dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Configure Environment Variables:**
   ```bash
   cp .env.example .env
   ```
   *(Edit `.env` to add your API key placeholders. Never commit `.env` to version control.)*
